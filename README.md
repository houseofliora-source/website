# House of Líora — Artisanal Soy Candles & Home Fragrance

> **Instagram:** [@houseofliorabd](https://www.instagram.com/_liora.bd_)  
> **Brand Identity:** High-end boutique, warm parchment palette, 100% botanical soy wax creations, Dhaka, Bangladesh.

---

## ✨ Features

- **Artisanal Product Catalog**: Hand-poured soy candles, bubble cubes, floating blooms, and classical sculpted forms with live scent/category filtering.
- **Interactive Scent Profile Quiz**: Personalized 3-step recommendation guide matching room mood and fragrance family.
- **Bespoke Wedding & Event Favor Studio**: Tier-discounted bulk order estimator with packaging options, wax seals, custom inscriptions, and 50% advance deposit policy.
- **Shopping Bag & Direct Checkout**: Cash on Delivery (COD) and bKash/Nagad payment handling with automated WhatsApp order summary link.
- **Candle Care Ritual & FAQs**: Soy wax maintenance, memory burn guides, and verified reviews.
- **Firebase Firestore Integration Ready**: Real-time catalog sync, order tracking, and patron records via Firebase Spark (Free) plan.

---

## 🛠️ Tech Stack

- **Framework:** React 19 (TypeScript)
- **Bundler:** Vite
- **Styling:** Tailwind CSS v4 (`@tailwindcss/vite`)
- **Icons:** Lucide React
- **Animations:** Motion
- **Database/Backend:** Firebase Firestore (Spark Plan) / LocalStorage Fallback
- **Hosting:** Vercel

---

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Locally
```bash
npm run dev
# Or on Windows:
npm run dev:win
```

### 3. Production Build
```bash
npm run build
# Or on Windows:
npm run build:win
```

---

## ☁️ Deployment (Vercel)

- **Framework Preset:** Vite
- **Build Command:** `npm run build`
- **Output Directory:** `dist`
- **Install Command:** `npm install`
